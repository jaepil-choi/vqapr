vqapr 0.16.0 시나리오 디버거 — 일곱 가지 일을 창고 한 채로, 파일이 생기는 순서까지

이 페이지는 vqapr이 실제로 무엇을 하는지를, 실제로 돌린 기록으로 보여 줍니다. vqapr new sample이 만든 작은 프로젝트(종목 10개, 2022-01-03 ~ 2024-12-30, 거래일 735일)에서 일곱 가지 일을 합니다: ① 데이터를 등록하고, ② 등록이 거절되는 두 경우를 보고, ③ 종목별 지표(5일 모멘텀)를 만드는 DataModel을 돌리고, ④ 그 지표로 상위 3개는 사고 하위 3개는 파는 factor 전략을, ⑤ 진입가를 기억해 3% 빠지면 파는 stop-loss 전략을 돌리고, ⑥ ④가 남긴 비중을 읽어 enhanced index를 만들고, ⑦ ④와 ⑤를 동시에(--jobs 2) 돌립니다. 이 판의 새 점: 모든 설명을 창고 한 채의 비유로 풀었고(아래 표), 장면마다 그 명령이 디스크에 남긴 파일을 트레이스의 파일 목록에서 뽑아 보여 줍니다(“창고” 상자, 그리고 “창고 연대기” 표). 파일이 생기는 순간(장부 쓰기, run.json, 작업 중 팻말, 표 봉인, 마감 도장)은 따로 프레임을 두었습니다. 읽는 법: 프레임마다 위쪽 문장은 보통 말이고, 아래 접힌 곳에 함수 이름과 호출 번호(#idx)와 ms가 있습니다. 코드 아래 카드는 그 파일이 무슨 파일인지, 맨 아래 src/ 지도엔 src/vqapr/의 파일 199개가 있습니다. 모든 번호와 ms는 sys.setprofile이 이번에 실제로 기록한 값이고(렌더러가 트레이스에서 직접 읽어 넣음), 체결 · 현금 · 비중은 그 run들이 쓴 기록에서 읽었습니다 — 상상한 것은 없습니다(experiments/exp_280_the_scenario_trace_0_16_0/).

먼저 알아 두면 편한 낱말 열둘

선언 (declaration) = 송장 — 당신이 쓰는 YAML. “이 parquet은 가격이다, 이 파일은 내 전략이다, 이 run은 이렇게 돌려라.” 창고는 송장을 믿지 않고 상자를 연다.
저자 표면 (vq) — from vqapr import public as vq. 저자가 쓰는 이름(StrategyModel · DataModel · Rebalance · Hold · DatasetInput …)은 전부 vqapr.public 한 곳에 있다.
등록부 (workspace) = 장부 — .vqapr/workspace.yaml. register가 쓰고 모든 명령이 맨 처음 펼쳐 읽는다. 항목마다 당신이 쓴 반쪽(컬럼 · 키 · 타입)과 검수대가 잰 반쪽(기간 · 지문 · 체결 가격)이 있다.
파일의 문 = 검수대 — 물리 파일을 실제로 열어 재는 한 곳(data/verification.py): 컬럼 · 키 · 기간 · 값 · 체결 가격 · 지문. 등록 때 한 번 재고, 그 뒤엔 내용이 아니라 지문만 대조한다.
digest = 봉인 번호 — 파일 바이트의 sha256. 한 바이트라도 바뀌면 번호가 달라진다. 이 트리(26726b1f)는 번호가 다르면 거절한다 — 바뀔 예정(오너 판정 2026-09-13: 다시 재고, 신고와 다를 때만 거절).
preflight = 출고 전 점검 — “이 run을 돌려도 되나”에 답하는 판정 일곱과 얼리기를 한 번의 읽기로(run/preflight/verdict.py). check도 run도 --jobs 일꾼도 이 한 함수를 지난다.
freeze = 작업 키트 — 장부의 이름들을 실제 값(코드 지문, parquet 경로와 지문, 시간표, 초기 계좌)으로 풀어 밀봉한 것 = FrozenRun. run 도중 장부가 바뀌어도 키트는 그대로다.
시간표와 사건 (schedule · event) — 선언의 schedule:이 결정 시각 목록을 만들고, 루프는 그 시각마다 ScheduledEvent 하나를, 체결 가격이 있는 시각마다 MarketEvent 하나를 시각 순서로 처리한다 — 조립 라인의 하루.
두 시계 — 시간표 시계: 결정하는 시각(08:00 · 09:00 · 16:00). 시장 시계: 체결표에 가격이 있는 시각(15:30). 아침에 주문서를 쓰고 오후에 체결 · 평가한다. 트레이스의 시각은 UTC라 06:30 = 15:30 KST.
창 (window) · panel = 재료판 — 전략이 읽는 데이터의 사각형: 시각 × 종목 행렬. run 기간 + lookback만큼만 한 번 읽어 두고, 결정마다 복사 없이 그 일부(view)를 본다.
memory = 작업자의 수첩 — 전략의 self.memory. 엄격한 JSON. 매 결정 전에 복원되고 뒤에 저장된다. 수첩에 적은 것만 믿을 수 있다.
run 기록 = 작업일지 — .vqapr/runs/<run>/. 표지(run.json)가 먼저, 본문(tables/*/all.parquet)이 끝에 한 번, 마감 도장(strategy.json)이 마지막. 도장이 있으면 본문이 다 있다는 뜻이다.

      filelock.py122줄한 번에 한 쓰기만 허용하는 잠금
