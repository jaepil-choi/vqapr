# vqapr 0.17.1 — a report outlives a book worth nothing, and a record names its vqapr

Released 2026-09-15 from `develop`. The five reports of scenario testbed run 5 (0.16.1 wheel),
closed by records `296`–`299` and one skill note. A patch on 0.17.0: nothing to register again,
no run identity changes, and a run records what it computed exactly as before.

## What changed

- **A declaration says what an edit replaced (record `296`).** `vqapr register <declaration.yaml>`
  now answers `replaced: {<component-id>: {fingerprint: <old>}}` when an edit moved a
  component's fingerprint, as `vqapr register <kind> <id> <file.py>` always did. Both routes take
  the answer from the merge, the one place that knows what the id held before.
- **Report sections are built one at a time (record `297`).** A section the record cannot give
  is `None` with its reason in `omitted`, and the other sections are still computed. A NAV that
  is not positive omits `performance`, `book` and `intent` (every number there is a share of
  NAV); `attribution`, `compliance` and `trading`'s money stay, and a turnover that opens at such
  a NAV is `None`. `vqapr export` writes `report.json` for such a record. `strategy_report` used
  to raise a bare `ValueError` and lose all six.
- **A record names the vqapr that wrote it (record `298`).** `strategy.json` and `datamodel.json`
  carry `package_version`; `vqapr show strategy` shows it; `vqapr.__version__` and
  `vqapr --version` answer. The version is a receipt, not part of a run's identity.
- **A batch says how long it took (record `299`).** An envelope that names several runs carries
  `elapsed`, and under `--jobs` also `bake`. The skills say that `timing.total` is one strategy's
  event loop only.
- **The skills say what a decision right after a fill reads**: the previous target's proportions
  (`make-strategy/references/reading-inputs.md`).

## Migrating a 0.17.0 tree

- Nothing to register again. A record written before 0.17.1 has no `package_version`.
- `StrategyReport.performance`, the return columns of `HeadlineRow` and `measure.relative` may be
  `None` — only where the call used to raise.
- Installed skills describe the old text. Install them again with `vqapr skill install --force`.
