# vqapr 0.17.0 — the budget is declared once, and the report measures against it

Released 2026-09-15 from `develop`. The strategy-budget campaign, records `291`–`292`, from the
owner's questions: how is a strategy's budget set, and how is a strategy that uses long 0.5 /
short 0.3 of its budget compared with one that uses all of it? **Breaking**: every strategy that
built its decision with `Rebalance.of`, `Rebalance.signed` or `Rebalance(target_weights=,
cash_weight=, budget=)` is rewritten, and a long-only strategy must now declare its budget.

## The budget is declared once, on the strategy (record `291`)

```python
class Alpha(vq.StrategyModel):
    def budget(self):
        return vq.Budget.flexible(long_limit=1, short_limit=-1)

    def decide(self, call):
        return vq.Rebalance(self.budget().fill(signal))
```

| declaration | long side | short side |
|---|---|---|
| `Budget.fixed(long=1, short=-1)` — the default | exactly 1 | exactly -1 |
| `Budget.fixed(long=0.5, short=-0.5)` | exactly 0.5 | exactly -0.5 |
| `Budget.fixed(long=1, short=0)` | exactly 1 | none |
| `Budget.flexible(long_limit=1, short_limit=-1)` | 0 to 1 | -1 to 0 |
| `Budget.flexible(long_limit=1, short_limit=0)` | 0 to 1 | none |

- **`budget()` is a declaration**, like `inputs()`: registration reads it (a value that is not a
  `Budget` is refused as `component.budget_invalid`), the run freezes it into the strategy's
  identity, and every `Rebalance` is checked against it at the decide stage. A book outside it
  stops the run as `rebalance.outside_budget` (422), naming each side's sum. Nothing is clipped
  and nothing is topped up.
- **A decision is weights only.** `Rebalance(weights)` takes one mapping of signed weights; cash
  is `1 - sum(weights)`. `self.budget().fill(signal, use=1)` sizes a signed signal to the declared
  sides on the canonical grid, relative conviction within a side; `use` takes part of a flexible
  budget. Under a fixed budget, a day that cannot fill a side is refused: declare `flexible` or
  return `Hold`.
- **Removed:** `Rebalance.of`, `Rebalance.signed`, the `target_weights=` / `cash_weight=` /
  `budget=` keywords (they now raise a `TypeError` naming the new spelling), `PortfolioDirection`,
  the five-bound `Budget`, the intent's budget, and `plan_orders(budget=)`. `BudgetRefusal` is
  exported from `vqapr.public`.
- **Borrowing (0.16.2) is a budget that nets above 1.** `Budget.fixed(long=2, short=0)` is 200%
  long with cash at -1 on a `cash_mode: BORROWING` account; a 130/30 book borrows nothing.
- `vqapr show model` prints the budget. The sample strategy declares one and imports from
  `vqapr.public` only (closes the 2026-09-14 report on its private import).

## The report measures use against it (record `292`)

- `strategy.json` states the budget (`budget`, in its constructor's spelling).
- `strategy_report(...).budget`: long, short and gross use per valuation, and the mean period
  return split as `mean_use_held × mean_return_at_full_use + timing`. Compare a strategy that used
  part of its budget with one that used all of it on `mean_return_at_full_use` and Sharpe, not on
  NAV return. The run headline gains `mean_use`.
- A 0.16 record states no budget; the report omits the section and says why.

## Migrating a 0.16 tree

| 0.16 | 0.17 |
|---|---|
| `Rebalance.of(long=L, invested=x)` | `budget()` → `Budget.flexible(long_limit=1, short_limit=0)`; `Rebalance(self.budget().fill(L, use=x))` |
| `Rebalance.of(long=L, short=S, invested=1)` | `budget()` → `Budget.fixed(long=0.5, short=-0.5)`; `fill({**L, **{k: -v for k, v in S.items()}})` |
| `Rebalance.signed(w, gross=2)`, filled to 1 / -1 | the default budget; `Rebalance(self.budget().fill(w))` |
| `Rebalance(target_weights=w, cash_weight=c, budget=B)` | declare the budget `B` meant on the class; `Rebalance(w)` |

- Register the edited strategies again; their fingerprints change with their source. A run's
  identity now folds the budget, so every run is a new record.
- Installed skills describe 0.16. Install them again with `vqapr skill install --force`.
